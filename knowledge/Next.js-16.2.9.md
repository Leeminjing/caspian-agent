# Next.js 16.2.9

Source: https://github.com/vercel/next.js/blob/canary/docs/01-app/02-guides/upgrading/version-16.mdx

### Next.js v16 주요 변경사항 및 기능

v16의 핵심 변경사항: Turbopack 기본 번들러, React 19.2 (View Transitions, useEffectEvent, Activity), React Compiler 안정화, Node.js 20.9+ 필요, Async Request APIs 필수, 캐싱 API (cacheLife, cacheTag, use cache), Middleware에서 Proxy로 이름 변경 등.

```markdown
## Turbopack by default

Starting with **Next.js 16**, Turbopack is stable and used by default with `next dev` and `next build`
```
